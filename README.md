Programming Assignment 4

How to Run

Start the Backend:
cd server
npm install
node server.js

Start the Frontend:
npm install
npm run dev

Open http://localhost:5173 in your browser.


Preparing Test Data

Create Users: Create users by signing up through the UI.

Create Project: Create a project with a name, description, and status, and assign a lead. Then add/manage project members.

Create User Stories: Select a project and create user stories with:

Three priorities (High, Medium, Low)

Three statuses (To Do, In Progress, Done)

Both assigned members and unassigned stories
